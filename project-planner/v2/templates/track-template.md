# Track template

`plans/track.md` is a simple history of the planning work, across all plans. Create it with the first plan. Add an entry when the user says "stop planning". New entries go at the bottom. If a session touched several plans, each plan gets its own line under the same date. Do not write "what comes next".

```markdown
# Plans — Track

## <YYYY-MM-DD>
- **<plan title> / <vX>:** <1–3 lines: what we did>. Stopped at: <where we stopped, or "nothing unfinished">.
```
