# Plan template

Use this as the starting point for a new plan file. Change the sections to fit the topic. The user must agree to the structure first. Remove sections that do not apply and add new ones when the user confirms them.

Only agreed things go into the sections below. Anything not agreed goes into "Open questions".

```markdown
# <Plan title>

## Overview
What we are planning, in a few lines.

## Previous plans
Only for a new version, or a plan that builds on other plans. Remove it otherwise.
This is plan <number> in the chain. It builds on: <plan-title/vX> (and <plan-title/vX>).
What this plan is for: <short description>

## Goal
What "finished" looks like.

## Limits
Deadline, time, budget, tools, who it is for.

## Starting point (what already exists)
Only when the plan builds on existing work or an earlier version. Remove it otherwise.
Facts about the existing work that the user confirmed, and only the ones relevant to this plan.

- <Confirmed fact>

## <Area 1, decided together>
Agreed items for this area. Each item has a short reason.

- <Agreed item> — Reason: <why we chose it>

## <Area 2, decided together>
...

## Out of scope
What this plan will NOT include.

## Steps
Agreed steps, in order. Each step says who carries it out (User or Agent), and has a status and a "done check".
An agent step is short: what to do, and which parts of this plan to follow.
Status: not started | in progress | done | needs rework

1. **<User / Agent>** — <Step>. Follow <parts of the plan>. — Status: not started
   - Done check: <how to see this step was done as planned>

## Replaced decisions
Old decisions that were changed. Keep the reason.

- <Old decision> → <New decision> — Reason: <why it changed>

## Open questions
Questions not decided yet. Also unfinished discussions saved when planning stopped.

- <Question or note: topic, options discussed, where we stopped>
```
