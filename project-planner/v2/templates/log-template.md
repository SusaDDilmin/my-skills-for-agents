# Log template

There is one log file per version, inside the version folder. Keep entries short and simple: what was decided, what changed, and why. Newest entry at the bottom.

```markdown
# <Plan title> <vX> — Log

## <YYYY-MM-DD>
- Took context from: <old version, for example plan-gallery-ui/v1> (only the first entry of a new version)
- Decided: <short decision> (<file>)
- Changed: <old> → <new>. Reason: <short reason>
- Split: <what moved where>
- Stopped at: <topic, if a discussion was left unfinished>
```
