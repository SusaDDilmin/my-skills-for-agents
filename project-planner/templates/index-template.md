# Index template

Create this file only when the plan is split into several files. It lists every plan file so the user and any agent can find things fast.

```markdown
# <Plan title> — Index

## Files
| File | What it contains | Status |
|------|------------------|--------|
| <path/file.md> | <short description> | draft / agreed / needs update |

## Step progress
Status: not started | in progress | done | needs rework

| Step | Status |
|------|--------|
| <Step name> | not started |

## Next step
<Which step comes next>

## Open questions
See the "Open questions" section in each file.
```
