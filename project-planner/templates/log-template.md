# Log template

There is only one log file for the whole plan. Keep entries short and simple: what was decided, what changed, and why. Newest entry at the bottom.

```markdown
# <Plan title> — Log

## <YYYY-MM-DD>
- Decided: <short decision> (<file>)
- Changed: <old> → <new>. Reason: <short reason>
- Split: <what moved where>
- Stopped at: <topic, if a discussion was left unfinished>
```
